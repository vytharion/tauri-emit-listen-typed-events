# tauri-emit-listen-typed-events

Type-safe Tauri 2 `emit` + `listen` — share event payload types between Rust and TypeScript with `ts-rs` codegen, plus a side-by-side `specta` comparison.

Companion code for the article: https://rust.nicedx.com/tauri-emit-listen-typed-events/

## Lessons

Each lesson lands as its own git commit so you can `git checkout <sha>` and follow along step by step. See the article for the full walkthrough.

## Run it

```bash
bun install
bun run tauri dev
```

Requires Rust 1.78+, Bun, and the Tauri 2 prerequisites for your platform.
